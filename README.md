# AstroTwin public judge demo

This repository is the public, static judge-facing build of AstroTwin.

- The verified TESS evidence, four guided analyses, and Photon Court planner are read-only snapshots derived from `P07-DEMO-REAL-TESS-20260829-028`.
- Judge Lab supports optional bring-your-own-key (BYOK) calls directly from the browser to Alibaba Cloud Model Studio (`dashscope.aliyuncs.com`).
- The API key is removed from the input immediately, held only in page memory while the run is active, and is never stored in this repository, browser storage, cookies, URLs, or generated results.
- Live BYOK output is a generated research plan, not evidence that a proposed experiment was executed.

The full research repository remains private; this public repository contains only the reviewed web demonstration bundle.
